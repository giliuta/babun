# supabase/parked — черновики, которые НЕ накачены

Здесь лежат миграции, написанные, но не применённые к боевой базе. Папка
`migrations/` — история того, что в базе есть; эта — того, чего в ней нет.
Перед накатом любого файла отсюда его сверяют с ЖИВОЙ базой: тела функций в
черновиках сняты в день написания и могли отстать.

Статус сверен с боевой базой 2026-10-27: черновиков здесь нет. Пакет из
31 черновика накачен на боевую 27.10 одним заходом (версии
`20261027155557`…`20261027160657`) и перенесён в `migrations/` с прежними
именами. Откат — по `ops.apply_snapshot_20261027` на боевой. Мини-пакет
28.10 (`20261028001000`, `20261028002000`) накачен так же (версии
`20261027165247`, `20261027165323`) и перенесён; откат — по
`ops.apply_snapshot_20261028`.
