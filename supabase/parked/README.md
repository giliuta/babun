# supabase/parked — черновики, которые НЕ накачены

Здесь лежат миграции, написанные, но не применённые к боевой базе. Папка
`migrations/` — история того, что в базе есть; эта — того, чего в ней нет.
Перед накатом любого файла отсюда его сверяют с ЖИВОЙ базой: тела функций в
черновиках сняты в день написания и могли отстать.

Статус сверен с боевой базой 2026-10-13. Устаревшие черновики удалены в тот же день: выход из компании, серия чеков
в `tenants` и компания как клиент — их место заняли живые миграции либо
откат модели компаний; квоты и лента календаря — их доделанные версии ушли
в `migrations/` (`20261013120000_quota_readers_closed`,
`20261013130000_calendar_feed_tokens`, ветка очистки 13.10).
