# design-sync — заметки по Babun

**Проект в Claude Design:** «Babun» — https://claude.ai/design/p/dbaa3ae9-258d-4583-8176-32481edc190c
(первая выгрузка 21.09: 70 блоков, 358 файлов). `projectId` закреплён в config.json.

**Вход:** `DesignSync` требует `/design-login` из ИНТЕРАКТИВНОГО Claude Code.
Команды `claude` в PATH на этом Mac нет — бинарь лежит внутри приложения:
`"/Users/artem/Library/Application Support/Claude/claude-code/<версия>/claude.app/Contents/MacOS/claude"`.
Запускать в панели терминала приложения (`run_in_terminal`), вход делает владелец.

## Как устроена сборка (важно для любого пересинка)

- Блоки Babun — **React Native** (Expo 54, RN 0.81, NativeWind 5 preview,
  react-native-web 0.21). Claude Design рисует в браузере, поэтому пакет
  собирается ДЛЯ ВЕБА тем же Metro, что и веб-версия приложения:
  `node .design-sync/build-web.mjs` (это `cfg.buildCmd`) → `ds-dist/`.
- Скрипт сам поднимает отдельный Expo-сервер на **:8083** с `BABUN_DS_WEB=1`
  и гасит его. Рабочий Metro приложения (:8081) не трогается. Долго живущий
  :8083 падал на повторных сборках («Got unexpected undefined» — инкрементальный
  граф Metro после правки входа), поэтому сервер каждый раз свежий.
- `BABUN_DS_WEB=1` в `apps/mobile/metro.config.js` подменяет `react`,
  `react/jsx-runtime`, `react-dom(/client)` на `window.React`/`window.ReactDOM`
  (`apps/mobile/ds-web/shims/`). Второй экземпляр React внутри бандла сломал бы
  хуки. Скрипт падает, если в бандл всё же попал свой React.
- Стили — Tailwind из `expo export --platform web` приложения (один css в
  `_expo/static/css/`) → `ds-dist/babun.css` → `cfg.cssEntry`. NativeWind 5 на
  вебе отдаёт `className` настоящими css-классами, поэтому статичного файла
  достаточно.
- Список блоков — `apps/mobile/ds-web/exports.ts` (новый блок = строка там).
  Значки — `export * as icons from "lucide-react-native"`: строчное имя, чтобы
  конвертер не сделал 1500 карточек; в дизайнах это `Babun.icons.<Имя>`.
- Описания свойств — `tsc` по `exports.ts`, пути `@/…` переписаны в
  относительные (ts-morph конвертера не знает paths из tsconfig).
- Обёртка всех карточек — `BabunProvider` (`apps/mobile/ds-web/BabunProvider.tsx`):
  жесты, safe-area (initialMetrics 390×844), тосты, шторки выбора.
- Плейрайт: в кэше `~/Library/Caches/ms-playwright/chromium-1234` → в `.ds-sync`
  стоит `playwright@1.62.0` (пинит сборку 1234). Ставить с
  `PLAYWRIGHT_SKIP_BROWSER_DOWNLOAD=1`.

## Правила авторинга примеров (выведены на Button, FieldRow, SelectRow, SectionCard)

- Импорт ТОЛЬКО из `'@babun/ui'` (блоки + `icons`). Никогда `react-native`,
  `lucide-react-native` напрямую — это вторая копия движка в карточке.
- Ширина телефона: `<div style={{ width: 390 }}>` для блоков во всю ширину,
  `358` для кнопок футера. Если ребёнок RN внутри DOM-обёртки должен тянуться —
  обёртке `display: 'flex', flexDirection: 'column'` (иначе строка сжимается по
  содержимому).
- FieldRow «ярлык слева, значение справа» с ДЛИННЫМ значением в браузере
  наезжает на ярлык (у `<input>` своя ширина) — там только короткие значения;
  длинный текст — `stacked`.
- Пустые строки показываем только там, где их показывает приложение. Пример:
  пустой side-by-side FieldRow в приложении живёт лишь в момент набора.
- Контент — живой, из домена (кипрский клининг/кондиционеры): клиенты «Павел
  Иванов», «Екатерина · жена», «Наталья», «Иван Петров · жилец · Вилла 5»;
  объекты «Вилла 5, Agiou Tychona 5, Limassol»; услуги «Чистка кондиционера
  €50»; счета «Касса», «Revolut»; команды «Команда 1». Цвета: бренд `#2c5be0`,
  деньги-приход `#087a52`, долг/удаление `#c9372c`, внимание `#9a6400`,
  текст `#0b1220` / `#5b6678` / `#66707e`.

## Known render warns

- `[RENDER_THIN]` у шести шторок (`BottomSheet`, `OptionSheet`, `PickerSheet`,
  `ValuePickerSheet`, `DateWheelSheet`, `AppearanceSheet`): модалка рисуется
  порталом поверх страницы, замер высоты корня видит 0. На снимках шторки
  целые, все клетки оценены good (21.09).

- `[FONT_MISSING] SystemAndroid` — не шрифт бренда: переменная `--font-sans`
  внутри `@media android` из `nativewind/theme.css`, в браузере не срабатывает.
  Приложение пишет системным шрифтом (SF на iOS), дизайны — тем же system-ui.
  Погашено `runtimeFontPrefixes: ["SystemAndroid"]`.

## Правила авторинга — добавлено по итогам пяти пакетов (21.09)

- **Обёртка — всегда flex-колонка**: `<div style={{ width: 390, display: 'flex', flexDirection: 'column' }}>`.
  RNW `Text` — `display: inline`; прямо в DOM-`div` он теряет `marginTop`, у
  переносящегося `RowCaption` получается висячий отступ, `SectionEyebrow`
  теряет верхний воздух, кнопка сжимается до подписи.
- **Клетки идут по алфавиту** (esbuild сортирует экспорты): каноничный пример
  называть так, чтобы он был первым (`ActionsBlock`, `DatesBlock`…). У
  `cardMode: single` карточка показывает первую по алфавиту — или `primaryStory`.
- **`adjustsFontSizeToFit` на вебе не работает** — длинное значение режется
  «…», а не ужимается. Значения держать короткими.
- **Голый DOM-текст в строке падает в serif** — строки собирать из блоков
  (`SettingsRow`, `ValueRow`, `SelectRow`); если нужен `<span>`, ему стек RNW:
  `-apple-system,BlinkMacSystemFont,"Segoe UI",Roboto,Helvetica,Arial,sans-serif`.
- **`position: fixed` в карточке схлопывается** (у корня карточки transform) —
  у шторок пример = сама шторка, без своей подложки.
- `ChoiceRow` без подписи и с шестерёнкой: четыре варианта не влезают в 358 —
  шестерёнка уезжает строкой ниже. Три варианта или вариант с подписью.
- `Badge` в `ControlRow` не класть: у бейджа `alignSelf: 'flex-start'`.
- `ScopeChips` сам прокручивает ленту к выбранному — в примере с «Добавить»
  выбирать первую команду, иначе первая обрезана.
- Колёса времени (`TimeWheelPair`, `LoopWheelColumn`) рисуются статично на
  заданном значении; `TimeRangePicker` всегда открыт на «Начало».
- `DateTimeInput` на вебе — поле браузера: в кадре формат en-US (`03/14/1987`),
  `locale` на вебе не работает.
- `SwipeRow` снят в покое — свайп статично не снять.
- Анимации (`LoadingBar`, `Spinner`) ловятся в кадре нормально.
- Команды в примерах: «Команда 1» `#3276FB`, «Команда 2» `#15A84F`.
- Инструменты: `sips --cropOffset 0 0` режет из центра — брать `1 1`; у каждого
  пакета помощников свой каталог обрезков — общий скрипт в общем scratch
  однажды перезаписали, и он насыпал 7707 файлов.

## Разбор владельца по выгруженным блокам (21.09 вечером)

Первый круг с живой дизайн-системой: владелец прошёл карточки и назвал, что
мусор, а что не по-нашему. Из этого вышли правки В САМОМ ПРИЛОЖЕНИИ (не в
примерах) — ровно то, ради чего выгрузка и делалась.

- **Снесены как мёртвые** (ноль мест отрисовки во всём `apps/mobile`):
  `SectionHeader` (`Card.tsx`), `StatusBadge` + словарь `APPT_STATUS`
  (`Badge.tsx`), `ColorDot` и `IconGlyph` (`picker-fields.tsx`). Ушли из
  `ds-web/exports.ts`, из `config.json` и из примеров.
- **Чип больше не пилюля**: `radius.card` (10), как у кнопки — «чтоб они были
  квадратные с закруглением, как кнопка». Сторож —
  `src/components/ui/chip-shape-contract.test.ts` (держит РАВЕНСТВО радиусов
  чипа и кнопки, а не число).
- **Действие пустого состояния уехало вниз**: `EmptyState.action` рисуется у
  нижнего края во всю ширину, а не компактной кнопкой по центру. Это чинит
  разом 45 экранов «Повторить» и «две двери» у справочников (пустой список
  звал кнопкой в центре, непустой — кнопкой в футере). То же у
  `ClientDataNotice`.
- **Выбор даты на вебе стал барабанами**: `DateSpinner` (+ `.web.tsx`) — три
  колонки «день · месяц · год» на CSS-привязке прокрутки, геометрия колеса
  времени (строка 40, видно три, две линии среза). `DateWheelSheet` рисует
  его вместо `<input type="date">`. Строки настроек с датой остались полем
  браузера — там дата стоит значением справа, и это не шторка выбора.
- **Реквизиты стали справочником как все**: строка — `SettingsRow` с
  `appearance` (плитка вида слева, под именем «Основные · AirFix LTD»), имя в
  карточке правится `NameColorField`. У компании появились `color` и `icon`
  (миграция `20260921220000_company_appearance.sql`, прогон в откате 6/6).

## Что сборка для Claude Design нашла в самом приложении (21.09, в дереве)

- `ReorderList` (списки-карточки: «Способы связи», услуги, категории, счета):
  анимированный стиль писал `backgroundColor: "transparent"` поверх белого фона
  строки — после первого перетаскивания строки становились серыми. Починено.
- Тумблер на вебе был «материальным» (бирюзовый кружок, у выключенного нет
  дорожки) — новый `SwitchControl` (+ `.web.tsx` в пропорциях UISwitch),
  `SwitchRow` на нём. Ещё 4 экрана с голым `<Switch>` — отдельной задачей.
- `Halo`: жёсткий id градиента «screenHalo» на вебе красил второй ореол цветом
  первого — теперь `useId()`, как у `PageWash`.
- `DateWheelSheet` на вебе: поле даты вплотную на «Применить» — просвет 12 только на вебе.
- Про импорт веб-двойников: алиас `@/` платформенные расширения ПОДХВАТЫВАЕТ
  (проверено опытом 21.09 — сборка `@/components/ui/SwitchControl` под web даёт
  `.web.tsx`). Старый комментарий об обратном в `DateWheelSheet.tsx` был неверен
  и исправлен.
- `StatusBadge` и `SectionHeader` нигде в приложении не использовались —
  владелец 21.09 сказал сносить; снесены вместе с `ColorDot` и `IconGlyph`.

## Дизайн-правки только для пакета

- В `babun.css` дописано правило: у открытой шторки на статичном кадре фокус на
  затемнении «Закрыть» давал синюю рамку `:focus-visible` по краю экрана — она
  погашена (только в пакете для Claude Design).
- `expo-router` в сборке для дизайна — пустышки (`ds-web/shims/expo-router.js`):
  «назад» в шапке без своего корня падал на `isReady`.
- Экспортированы помощники прототипа: `useToast`, `confirmAction`, `chooseOption`.

## Re-sync risks — что может тихо устареть

- `ds-dist/` собирается из РАБОЧЕГО дерева `apps/mobile`: незакоммиченные правки
  блоков уезжают в дизайн-систему. Синк — после коммита блоков.
- `babun.css` — из `expo export`: экспорт должен проходить (lightningcss
  закреплён 1.30.1 в корневом package.json). Новые Tailwind-классы в блоках
  попадают в css только через экспорт — `--skip-css` при их появлении нельзя.
- Пустышка `expo-router` (`ds-web/shims/expo-router.js`) знает только то, что
  зовут блоки сегодня (`useRouter`, `useFocusEffect` и соседей). Новый вызов —
  дописать туда, иначе блок упадёт в дизайне.
- Порт 8083 должен быть свободен: сборка поднимает на нём свой Expo.
- Плейрайт закреплён на кэшированном Chromium 1234 (`playwright@1.62.0`). Обновится
  кэш — подобрать версию заново (см. скилл, §4.1).
- Все карточки в группе `general` (+ `ds-web` у BabunProvider): группа берётся
  из пути, а `components/ui` — «общее» имя. Разложить по группам можно JSDoc
  `@category <latin>` у блоков — кириллица в имя группы не проходит (slug).
- Примеры держат домен (Павел/Екатерина/Наталья/Вилла 5, VAT 19%) и цвета команд
  `#3276FB`/`#15A84F` — при смене слов продукта править примеры.
- Мёртвые блоки сносятся В ПРИЛОЖЕНИИ, а не прячутся из выгрузки: выгрузка
  показывает то, что есть. 21.09 так ушли `StatusBadge`, `SectionHeader`,
  `ColorDot`, `IconGlyph` — вместе с примерами и записями в config.json.
