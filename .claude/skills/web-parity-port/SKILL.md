# Веб → Мобайл: портирование с паритетом 1:1

Веб (источник истины): `/Users/artem/Documents/babun2/babun-crm/apps/web`
Мобайл (цель): `/Users/artem/Documents/babun2/babun-crm/apps/mobile`
Спеки: `apps/mobile/docs/PORT-SPECS.md`, аудит паритета: `apps/mobile/docs/WEB-PARITY-AUDIT.md`, план: `docs/EXPO-RN-MIGRATION-PLAN.md`.

## Workflow слайса

1. **Прочитай веб-реализацию целиком** — компонент, его хуки, данные, все состояния (пустое/загрузка/ошибка/переполнение). Паритет = поведение, не только вид.
2. Найди утверждённые решения в памяти/доках (многие экраны имеют LOCKED-дизайн, отличающийся от текущего веба — например финансы v5, карточка клиента «Карта-диспетчер»). LOCKED-дизайн важнее текущего веба.
3. Портируй одним слайсом: экран в `app/`, логика в `src/features/<фича>/`, данные через TanStack Query + Supabase (веб местами держит данные в localStorage — на мобайле это Supabase или MMKV, см. существующие фичи).
4. Стиль — только токены Halo Cobalt (скил halo-cobalt-check), НЕ копируй веб-CSS буквально.
5. Верификация на симуляторе (скил babun-sim): обе темы, пустое состояние и состояние с данными.
6. Коммит: `feat(mobile): <что> (web parity)` — ветка `feat/mobile-app-port`, пуш только по просьбе пользователя (напрямую в master нельзя — только PR через gh).

## Известные грабли

- NativeWind v5-preview: circular-init крашит RN-web на FlatList-экранах → Expo web не использовать для проверки, только симулятор.
- Даты: веб-календарь считает недели с понедельника, суббота/воскресенье красные; границы суток — локальная TZ.
- В заголовках дат «г.» не пишем («Июль 2026», не «Июль 2026 г.»).
- `bun`/`bunx`/`python3`; node в PATH отсутствует.

## Чек-лист приёмки слайса

- [ ] Все состояния веба воспроизведены (пустое, загрузка, ошибка, много данных)
- [ ] Обе темы, safe areas, клавиатура не перекрывает поля
- [ ] Токены вместо хардкода; сиблинги консистентны
- [ ] typecheck проходит: `cd apps/mobile && bunx tsc --noEmit`
- [ ] Скриншот с симулятора приложен в ответ пользователю
