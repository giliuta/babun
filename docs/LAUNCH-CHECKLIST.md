## Купить (решение и оплата — владелец)

- [ ] **Supabase Pro** — ~$25/мес. Дневные копии за 7 дней, без пауз,
      поддержка. Organization → Billing → Upgrade to Pro.
- [ ] **Сервер Small (2 ГБ)** — ~+$15/мес. Settings → Compute and Disk
      (перезапуск 2–3 мин, делать ночью).
- [ ] **Spend cap** в Billing — счёт не вырастет неожиданно.
- [ ] **Своя почта для писем** (Resend или аналог): встроенная почта
      Supabase шлёт лишь несколько писем в час — приглашения и сброс
      пароля начнут теряться. Authentication → SMTP.
- [ ] **Vercel Pro** (~$20/мес), если нужна веб-версия babun.app:
      бесплатный Vercel нельзя для коммерческого продукта.

Цены приблизительные — сверять на страницах тарифов.

## Когда расти дальше

Сигнал к следующему серверу — любое из:
- память стабильно больше 80%;
- появилась подкачка;
- процессор долго ждёт диск.

Где смотреть: Supabase → Observability → Database.

## Если база легла

1. Проверить status.supabase.com — если сбой у Supabase, ждать.
2. Там всё зелёное → Supabase → Babun → Settings → General → Restart
   project. Данные сохраняются, 2–5 минут.
3. Не помогло → поддержка Supabase.
