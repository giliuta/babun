7. **Верификация на симуляторе** (iPhone 17 booted, dev-build, Metro :8081):
   - перезапуск: `xcrun simctl terminate booted com.babun.crm; sleep 2; xcrun simctl launch booted com.babun.crm; sleep 15`
   - навигация: `xcrun simctl openurl booted "babun:///<route>"` (expo-router пути: clients, finances, chats, cabinet, cabinet/close-day, cabinet/unclosed, cabinet/labels, cabinet/sms-templates, …)
   - скриншот: `xcrun simctl io booted screenshot /tmp/shot.png && sips -Z 900 /tmp/shot.png` → смотреть Read'ом
   - темы: `xcrun simctl ui booted appearance dark | light` — каждый изменённый экран проверять в ОБЕИХ
   - ошибка «Network request failed» после сна Mac — транзиентная, лечится перезапуском приложения.
8. **Метод**: большие куски дели на зоны с ЭКСКЛЮЗИВНЫМ владением файлами; после каждой волны — адверсариальное ревью диффа (корректность + паритет + консистентность) и дофикс. Каждая правка минимальна.
