# Все блоки, которые можно включать и выключать

Список для владельца. Каждая строка — одна функция, которую можно дать или не
дать сотруднику. Пройдите и отметьте, что **не вносим**.

**Пометки:**

- `живой` — сервер уже проверяет, переключатель работает.
- `есть` — строка в реестре заведена и фраза написана; переключатель
  появится на странице в тот день, когда у блока появится сторож на сервере.

**21.09 в реестр заведены все недостающие блоки. После снятия мешка
«Категории, шаблоны, НДС» и «Заметки записи» их 50, живых тринадцать.** Дальше идём волнами:
каждая делает живым один блок или небольшую группу.

**Положения:** «Скрыт» — не видит · «Смотрит» — видит, не меняет · «Меняет» —
видит и меняет. Где «Скрыт» бессмыслен (без валюты сумму не показать),
положений два.

## Что вскрылось попутно (уже починено 21.09)

1. **Деньги записи жили мимо прав** — мастер принимал наличные при любых
   финансовых уровнях. Блок «Оплата в записи» стал живым.
2. **Телефон уходил мимо «Телефонов и контактов»** — второй дорогой, через
   клиента записи. Закрыто.
3. **Мина под новым сотрудником**: без служебной строки «Календарь и записи»
   у человека не работал НИ ОДИН календарный блок, включая финансы.
   Прикрепление к календарю теперь ставит её само.
4. **Мастер не видел фото своих записей вовсе** — после волны «Фото и
   файлы» 21.09 проверка шла мимо него при любом положении. Починено в тот
   же день, фото на записях мастеров ещё не было.
5. **Файлы записи можно было скачать при «Скрыт»** — хранилище спрашивало
   старое правило. Теперь то же, что у экрана.
6. **Вы теряли фото записей из удалённых календарей.** Владелец теперь не
   ограничивается ничем, жив календарь или нет.
8. **Мастер не видел ни одной цены**, какие бы права ни стояли: окно записей
   обнуляло деньги для всех. Теперь «Работы» с ценами и «Итого» — по «Сумме
   записи», статус оплаты — по «Оплате». У Дмитрия «Сумма» стоит «Смотрит» —
   так вы выставили 15.09 («Меняет» стало «Смотрит»: правки в записи у мастера
   ещё нет).
7. **Карточка записи у мастера не смотрела на права** — кнопки статуса и
   загрузка фото оставались и падали отказом. Теперь каждый блок записи
   виден ровно по своему положению.

## Что вскрылось и ждёт решения

- **Страница «Счета» заперта грубым замком** «только владелец» поверх
  уровней: сервер сотрудника с «Меняет» уже пускает, а экран — нет.
- **Вся страница «Настройки клиентов» закрыта целиком** — ни одна из её строк
  не имеет своего уровня.
- **Аналитика считается по третьей системе прав** — ни реестр, ни уровни её
  не касаются.
- **«Мастера» показывают деньги**: визиты и статистика мастера с выручкой
  сидят внутри блока «Мастера», без отдельного права на суммы.
