# STORY-089 — SMS: разбор конкурентов и новая структура (24.09)

Владелец 24.09:
- «несколько шаблонов: новая запись — свой шаблон, напоминание — свой,
  отмена — свой… настройка каждого»;
- «шаблон под каждую команду, отправка через команду один, сколько
  сообщений ушло через команду один, сколько через команду три»;
- «можно добавить полноценно SMS в каждую команду в календаре».

## Что смотрели (18 продуктов)

- **Выездные сервисы:** Jobber, Housecall Pro, ServiceTitan, Workiz,

- **Онлайн-запись:** YCLIENTS, Altegio, Fresha, Booksy, Vagaro, Square

- **Twilio на Кипре.**

Отчёты агентов со ссылками на источники — в стенограмме сессии 012

## Главное из исследования

1. **События у всех разделены.** У каждого своё включение и свой текст:
   - новая запись;
   - напоминание — 1–3 штуки с разным временем;
   - перенос;
   - отмена;
   - после визита — спасибо или отзыв;
   - повторный визит через N дней или месяцев.
2. **Слои настроек:** компания → филиал или команда → услуга → конкретная
   запись. У YCLIENTS так: по умолчанию «как у сети», пока филиал не
   поменял своё.
3. **Подтверждение ссылкой.** Клиент жмёт «Подтвердить» — запись в
   календаре меняет статус. Так у YCLIENTS, Square, Vagaro, Jobber.
4. **«Еду к вам» с временем прибытия** отправляет мастер из приложения.
   Есть у Jobber, Housecall Pro, Workiz, ServiceM8, Tradify, GorillaDesk.
5. **Баланс** (лучше всех у Fresha):
   - бесплатные сообщения каждый месяц;
   - купленные не сгорают;
   - автопополнение по порогу;
   - журнал пополнений;
   - на нуле отправка просто останавливается.
6. **Журнал сообщений** в записи и в карточке клиента: время, событие,
   статус, текст (YCLIENTS).
7. **Отказ клиента** — по категориям: служебные отдельно от рекламных
   (Mindbody, YCLIENTS).

**Чего нет ни у кого:**
- статистики SMS по командам или мастерам — количество, стоимость,
  доставка;
- тихих часов, заданных настройкой.

И то и другое мы можем сделать первыми.

## Кипр: жёсткие рамки (Twilio)

- Отправитель — имя буквами (до 11 знаков), без регистрации. «Babun» или
  имя компании.
- **Двусторонних SMS нет:** клиент не может ответить, STOP не работает.
  Подтверждение и отказ — только ссылкой в тексте.
- **Цена Twilio — $0,0864 (≈ €0,08) за часть.** Кириллица — 70 знаков на
  часть, 67 при нескольких частях. Напоминание на 150 знаков = 3 части.
  Наша цена €0,10 за часть почти без наценки. Для сравнения: Fresha
  берёт €0,12 за текст, Tradify — £0,10.

## Структура, которую предлагаю

**События** — у каждого свой текст и своё включение:

| Когда | Событие | Время |
|---|---|---|
| До визита | Новая запись (подтверждение) | сразу |
| До визита | Напоминание 1 | за N часов, по умолчанию за сутки |
| До визита | Напоминание 2 | за N часов, по умолчанию выкл. |
| Изменения | Перенос | сразу |
| Изменения | Отмена | сразу |
| После визита | Спасибо / отзыв | через N часов после окончания |
| После визита | Пора повторить (сезонная чистка) | через N месяцев |
| Вручную | Еду к вам | мастер жмёт в записи, выбирает «через 15/30/60 мин» |

**Слои:** текст компании по умолчанию → «свой текст» у команды. Команда
видит «Как у компании», пока не поменяет своё.

**Статистика по командам:** за месяц — сколько SMS, частей, стоимость,
доставлено / не доставлено. История с отбором по команде и событию.

**Общие настройки компании:**
- тихие часы (по умолчанию 21:00–08:00);
- отправитель;
- цена за часть — видна только на сайте.

### Где это живёт — три варианта

1. **Всё в «Клиенты» → «SMS».** Внутри раздел по каждой команде.
2. **Всё в командах календаря.** У каждой команды свой блок «SMS».
3. **Разделить (рекомендую).**
   - «Клиенты» → «SMS» — общее для компании: баланс, статистика по
     командам (строка на команду, тап — её страница), тексты по
     умолчанию, тихие часы, шаблоны для ручной отправки, история.
   - Календарь → команда → «SMS» — своё у команды: включить, события
     этой команды («Как у компании / Свой текст»), её статистика.
