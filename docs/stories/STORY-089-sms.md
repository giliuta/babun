# STORY-089 — SMS: шаблоны, свой телефон, сервис, баланс

Владелец 24.09:
- «подключим шаблоны SMS, первое — чтоб можно было по шаблону отправлять со
  своего личного телефона, и потом чтобы автоматически отправлялось через
  специальный сервис… максимально удобно для SaaS»;
- «у них есть собственный кабинет отправки СМС… он может разрешать
  отправлять с этой командой СМС или не отправлять… он видит баланс…
  пополняет через нашу CRM свой кабинет, и с его счёта списывается за
  каждую СМС»;
- «чтоб пополнять без комиссии… чтоб не брал Apple… все подписки будем
  оформлять через сайт».

## Что было на 24.09 (инвентаризация)

- Сервер: `send_sms` (Twilio) в базе — майский черновик. Расписание дёргает
  его каждые 5 минут, общий выключатель `app_settings.sms_enabled = off`.
  Нет ни одной компании с настройками SMS, не отправлено ни одной SMS.
- Баланс и пополнение: `tenant_sms_config.balance_cents` / `free_sms_remaining`,
  `reserve_sms_credit` / `release_sms_credit` (10 центов за SMS, без счёта
  частей), `sms_topups` и `stripe-webhook` (не развёрнут). Кто создаёт
  оплату Stripe, в репозитории нет — это был удалённый веб.
- Шаблоны живут в трёх местах, у каждого свой синтаксис:
  - приложение — `[Имя]` в `tenant_state.prototype_state.smsTemplates`;
  - сервер — `{client_name}` в `tenant_sms_config.template_24h/2h`;
  - запись — `{name}` в `appointments.reminder_template`.
  Друг с другом они не связаны.
- Экран шаблонов (`cabinet/sms-templates`) ни откуда не открывается.
  Переключатель напоминания в записи пропал: `reminder_enabled` у новых
  записей всегда false.
- Нет отказа клиента от SMS, нет проверки чёрного списка, берётся сырой
  `phone`, а не `phone_e164`.

## Решения (принимаю сам, по закону «решай сам»)

- **Один канон шаблонов** — приложение, `[Имя]`. Сервер переходит на него;
  `template_24h/2h` и `reminder_template` уходят из работы.
- **Оплата — только на сайте** (babun.app, Stripe). В iOS-приложении — баланс
  и история, ни цены, ни кнопки, ни ссылки (правило Apple и решение
  владельца).
- **Сервис** — Twilio: отправка, подпись статусов и списание уже написаны.
  Отправитель — имя компании буквами, если страна разрешает, иначе «Babun».
- **Цена — за часть SMS**, а не за сообщение: кириллица — 70 знаков на
  часть. Цена за часть — одно число в базе (`app_settings`), не в коде.
- **Разрешение по календарям**: владелец включает автоматические SMS для
  каждого календаря отдельно на странице SMS.

## Волны

1. **Со своего телефона** (без сервиса и без денег):
   - «SMS» в листе «Связаться» у номера открывает шаблоны. Видны только
     те, что заполняются целиком из записи или карточки клиента; тап
     открывает «Сообщения» с готовым текстом;
   - строка «SMS» в Кабинете → страница SMS (владельцу) с блоком
     «Шаблоны»;
   - шаблоны читает сотрудник с правом «Шаблоны SMS», рассылка — по праву
     «Рассылка по выбранным».
2. **Сервис**:
   - сервер читает канон шаблонов;
   - автоматические SMS: новая запись, напоминание за N часов, отмена — по
     календарям;
   - «Отправить через сервис» из записи и карточки;
   - списание за части, отказ клиента от SMS, `phone_e164`, статусы
     доставки, история на странице SMS;
   - расписание не будит функцию, пока ни одна компания не включила
     автоматические SMS.
3. **Пополнение на сайте**: страница babun.app (только веб) → оплата Stripe
   → вебхук зачисляет баланс. Аккаунты Twilio и Stripe заводит владелец —
   это пункт чек-листа запуска.

### Волны 2–3 — сервис, баланс, пополнение на сайте (24.09)

Сервер `20260924220000_sms_service` (прогон в откате ~30 проверок, накачен,
17 тел = файл). Мозг — в базе:
- **очередь** `sms_messages` ('queued' → 'sending' → 'sent' / 'failed' /
  'blocked');
- **автоматически:** триггер записи (новая → подтверждение, отмена) и тик
  раз в 5 минут (напоминание за N часов, тихие часы 21–08 по календарю);
  прошлое не извещаем;
- **разрешение:** выключатель платформы (`app_settings.sms_enabled`),
  выключатель компании, календарь среди разрешённых, у клиента номер, нет
  отказа и чёрного списка;
- **деньги:** цена за часть в `app_settings.sms_price_cents_per_segment`
  (10 центов); сначала бесплатные части, потом баланс; отказ Twilio
  возвращает; не хватило — 'blocked';
- **ручная отправка** `sms_send_manual`: по записи — тот, кто видит её
  календарь; из карточки без записи — владелец;
- **закрыты две дыры заготовки:**
  - журнал SMS читал любой сотрудник (номера и тексты);
  - владелец мог одним UPDATE переписать себе баланс.

Функции на сервере (ещё не развёрнуты):
- `send_sms` — переписан курьером: забрать → собрать текст (`render.ts`) →
  посчитать части (`encoding.ts`) → списать → Twilio. Копии правил
  приложения держит `server-render-parity.test.ts`; мутанты ловит.
- `twilio-status`:
  - «в пути» у Twilio больше не возвращает сообщение в нашу очередь.
    Раньше курьер отправил бы его второй раз со вторым списанием;
  - запоздалый статус не затирает доставленное.
- `stripe-webhook`:
  - зачисление — атомарная `sms_credit_topup`, сумма — `amount_total`;
  - зачисление стоит до журнала, сбой отвечает 500. Раньше сбой
    зачисления отвечал 200, и оплата терялась навсегда.
- `sms-checkout` (новая) — владелец открывает Stripe Checkout на
  10/25/50/100 €; возврат только на babun.app.

Приложение:
- Кабинет → «SMS» (владельцу) — страница:
  - Баланс, За месяц;
  - Отправка через сервис: выключатель и календари;
  - Автоматически: новая запись, напоминание и когда, отмена — шаблон или
    «Не отправлять»;
  - Шаблоны;
  - История: 5 последних + «Вся история».
  На вебе футер «Пополнить баланс» → сумма → Stripe. В iOS нет ни кнопки,
  ни цены.
- Лист «SMS» у номера: «С телефона | Через сервис», когда сервис доступен
  здесь. Через сервис у шаблона видна цена: на iOS — части («2 SMS»), на
  сайте — евро. Тап отправляет.
- Карточка клиента → «Личное» → «Присылать SMS» (отказ клиента, своя
  функция базы).

Проверено на симуляторе от лица владельца:
- страница SMS;
- выключатель и календарь;
- выбор шаблона на новую запись → строка настроек в базе;
- сервис включён на минуту → лист у номера показал «Через сервис» и
  «€0,20» → тап → «SMS отправляется», в очереди строка с текстом, номером,
  календарём и автором → пробуждение дошло до функции (200);
- «История SMS» показала сообщение;
- «Присылать SMS» туда и обратно.

После проверки всё возвращено как было: сервис выключен, настроек SMS у
Giliuta нет, тестового сообщения нет, запись 20.09 не менялась.

### Выкладка (24.09, по слову владельца «заполни всё, что надо»)

  `…/functions/v1/stripe-webhook`, события `checkout.session.completed` и
  `checkout.session.async_payment_succeeded` (012 через Chrome). Ключи
  `STRIPE_SECRET_KEY`, `STRIPE_WEBHOOK_SECRET` владелец вставил сам.
- Twilio: ключи уже были в секретах. Старый секрет
  `TWILIO_STATUS_CALLBACK_URL` указывает на мёртвый адрес удалённого веба —
  код его больше не читает, статусы идут в `twilio-status`.
- Функции выложены: `send_sms` v4, `twilio-status` v3, `stripe-webhook` v3,
  `sms-checkout` v1. Пробы без отправки: 401 / 400 «нет подписи» / 400 / 401
  — ключи Stripe подхватились.
- Осталось: включить `sms_enabled` и первая SMS на номер владельца.

### Волна 4 — события × команды (24–25.09)

Владелец: «новая запись — свой шаблон, напоминание — свой, отмена — свой…
шаблон под каждую команду… сколько ушло через команду один, сколько через
команду три». Разбор конкурентов — `STORY-089-sms-analysis.md`. Решения:
всё в «Клиенты» → «SMS», раздел на каждую команду; цена €0,12 за часть.
- База (`20260925020000_sms_rules`, накатана 25.09 по слову владельца,
  14 функций сверены по md5 с файлом): таблица `sms_rules` (компания `''` /
  команда × событие); семь событий — новая запись, два напоминания, перенос,
  отмена, «Спасибо», «Пора повторить»; тихие часы компании (`send_after`,
  по умолчанию 21–08); `for_start` — после переноса напоминание уходит о
  новом времени; счёт месяца по командам в `sms_account`; история с отбором
  по команде и событию; `sms_save_rule`. Старые `auto_*` и `reminder_hours`
  сняты (строк не было).
- Пробы с откатом: 22 шага — умолчания, правила, отказы, сотрудник, права,
  тихие часы, подтверждение, перенос, напоминания (один раз, повтор о новом
  времени), отмена, «Спасибо», «Пора повторить», очередь по сроку, счёт.
- Экран: «SMS» — Баланс, Отправка (+ тихие часы), Команды (SMS за месяц,
  свои тексты, € — тап в страницу команды), До визита / Изменения / После
  визита, Ручная отправка, История. Страница команды — отправка, счёт
  месяца, события «Как у компании / Свой текст / Не отправлять», история
  команды. Один лист события на оба слоя; поле текста вынесено в
  `SmsTextField`. В ручные шаблоны добавлен готовый «Еду к вам».
- Проверено на симуляторе (AirFix): страница, страница команды, лист,
  запись «Свой текст» до базы и обратно — вернули, правил в базе 0.
- Потом: ссылка «Подтвердить / Отменить», отказ по ссылке, автопополнение,
  журнал SMS в записи и карточке клиента.
