# Услуга: одно количество = ОДНА СТРОКА — спецификация (2026-08-25)

Приговор владельца 2026-08-25 дословно: «я хочу чтоб это было в одну строчку, то есть не
полноценный какой-то здоровый блок и под каждое всё три блока огромное — нет, одна маленькая
аккуратная».

Это пятый заход. Документ отвечает на один вопрос — **как уместить количество · цену · время ·
(расход) в одну строку 346pt и оставить это правимым пальцем** — и не является кодом. Всё, что
названо законом, уже записано в `apps/mobile/docs/DESIGN-SYSTEM.md`,
`docs/audit/SERVICE-ROWS-2026-08-21.md`, `SERVICE-EDITOR-DESIGN-2026-08-21.md`,
`SERVICE-TABLE-SPEC-2026-08-24.md`.

При **16pt**: цифра 9,6 · буква 8,8 · пробел 4,48 · € 9,28 · запятая 4,32 · минус 5,6.
При **15pt**: цифра 9,0 · буква 8,25 · пробел 4,2. При **11pt** капс: буква ≈6,8 + трекинг 0,8.

## 1. Почему падали четыре попытки — одной фразой на каждую

| # | Что было | Почему упало |
|---|---|---|
| 1 | Одна карточка, три колонки | У таблицы из ОДНОЙ строки колонок не существует физически, а одна строка — это 5 услуг из 6 |
| 2 | Четыре залитые плиты + шапка колонок | То же самое плюс шапка, подписывающая пустоту |
| 3 | `ValueRow`, каждое число своей строкой | Работало, но лестница переставала быть лестницей: 4 строки на одно количество |
| 4 | Блок-карточка, внутри 2×2 таблички | «Не полноценный здоровый блок» — 162pt на ОДНО количество, 500 на лестницу |

Общий знаменатель всех четырёх: **подпись занимала место рядом со своим числом.** «Расход за
всё» — 79,3pt при 12pt кегле, это ширина, сравнимая с самим числом. Пятая попытка обязана убрать
подпись с экрана, не убрав смысл.

**Ход, который это разрешает, уже лежит в базе прода.** Строка счёта «Трасса, 4 м» доказывает: у
числа с единицей подписи не нужно. `4 м` — количество, `€20` — деньги, `1 ч 30 мин` — время. Частица
(«шт», «€», «мин») ЕСТЬ подпись, и она в 3–5 раз у́же слова.

## 2. Три однострочные анатомии

Доска: `402 − 2×16 (гуттер листа) = 370pt`. Строки живут в ОДНОЙ белой карточке группы
(`t.surface`, радиус 10), внутреннее поле по 12 → **346pt на содержимое строки**.

### Вариант А — САМОПОДПИСАННЫЕ ТОКЕНЫ (подписей нет вовсе)

`[кол-во][цена][время][расход]`, каждое значение несёт свою частицу. Ни одного слова-подписи в
строке. Режим «за всё / за 1 м» и выбор единицы переезжают в ОДНУ панель услуги, открываемую
чипом в эйбрау группы и тапом по частице единицы в любой строке.

Арифметика (худшие значения при обычном кегле):

| Слот | Ширина | Худшее содержимое | Занимает | Запас |
|---|---|---|---|---|
| Количество | 72 (с «от») / 56 (без) | «от 128 м²» = 20,7+28,8+4+13,5 | 67,0 | +5,0 |
| зазор | 8 | | | |
| Цена | flex, мин **78** | «€1 250,50» | 78,7 | −0,7 → `minimumFontScale 0.9` |
| зазор | 12 | шов между вводом и барабаном — не 8 | | |
| Время | 96 | «23 ч 55 мин» | 87,0 | +9,0 |
| зазор | 8 | только когда есть расход | | |
| Расход | 72 | «−€1 250» = 5,6+9,28+9,6+4,48+28,8 | 57,8 | +14,2 |

**Суммы закрываются точно, во всех четырёх раскладах:**
* лестница + расход: `72+8+78+12+96+8+72 = 346` ✓
* лестница без расхода: `72+8+158+12+96 = 346` ✓ (цена забирает освободившиеся 80)
* одна строка без расхода: `56+8+174+12+96 = 346` ✓
* одна строка + расход: `56+8+94+12+96+8+72 = 346` ✓

Типичные значения дышат: «1 шт» 30,1 в 56 · «€50» 28,5 в 174 · «30 мин» 50,1 в 96 · «−€18» 34,1 в 72.

**Что теряет.** Слово «Расход» уходит с экрана: два денежных числа в строке различаются только
знаком «−» и приглушённой краской. Слова «Цена за всё» на строке тоже нет — режим читается один
раз в эйбрау. Новичок в первую секунду не знает, что второе € — это расход (в озвучке и в панели
знает; глазом — по знаку).

### Вариант Б — ЧЕТЫРЕ МИНИ-ТАБЛИЧКИ В ОДИН РЯД (подпись 11pt над числом)

Тот же нынешний блок, сплющенный в один ряд: `(346 − 3×8)/4 = 80,5pt` на табличку.

Арифметика убивает вариант дважды:
* «Расход за всё» при 12/500 = 79,3 ≤ 80,5 — влезает с запасом **1,2pt**;
* при `maxFontSizeMultiplier 1.2` = 95,2 > 80,5 → перенос на вторую строку → строка вырастает в
  два этажа, то есть обратно в забракованный блок;
* сократить подпись до «Расход» (47,5) можно, но тогда слова «за всё» нет НИГДЕ, и переключатель
  режима теряет свою единственную поверхность.

**Что теряет.** Устойчивость к системному шрифту — целиком. И это не строка, а блок высотой 44–48
с четырьмя заливками: ровно та плотность, которую владелец забраковал.

### Вариант В — СТРОКА-ФРАЗА, РЕДАКТОР ПО ТАПУ

Строка печатает готовый текст (`tierSummary` уже написан): «от 3 · €135 · 1 ч 30 мин». Одна
`Text` с `adjustsFontSizeToFit`, влезает ВСЕГДА и на любом экране. Тап раскрывает под ней редактор
на три поля.

**Что теряет.** Правку. Пять услуг из шести — одна строка, и самое частое действие в листе (сменить
цену) становится двухтапным: раскрыть → попасть в поле. Лестница читается идеально, обычная услуга
работает хуже, чем сегодня. Кроме того, раскрытый редактор — это опять блок, просто отложенный
на один тап.

### Сводка

| | А | Б | В |
|---|---|---|---|
| Влезает при обычном кегле | ✓ точно в 346 | ✓ с запасом 1,2pt | ✓ всегда |
| Влезает при ×1,2 | ✓ (два поля жмутся до 0,9) | ✗ подпись переносится | ✓ |
| Держит расход | ✓ четвёртым токеном | ✗ | ✓ во фразе |
| Правится одним тапом | ✓ | ✓ | ✗ два тапа |
| Высота одного количества | **48** | 48 (76 при ×1,2) | 48 + 160 раскрытым |
| Лестница из трёх | **146** | 146 | 146 |

## 3. Выбор: ВАРИАНТ А

Три довода, ни одного про вкус.

1. **«Одна маленькая аккуратная» — это 48pt против 162.** А — единственный вариант, где ОДНО
   количество занимает одну строку списка и ничего не раскрывает, чтобы себя показать.
2. **Подпись убита правильным способом.** Не сокращена, не спрятана в тултип — заменена частицей,
   которую человек и так печатает в счёте («Трасса, 4 м»). Это тот же ход, что вернул единицу
   измерения в продукт 24.08, доведённый до конца.
3. **Лестница читается как прайс сверху вниз без единого тапа** — числа стоят в фиксированных
   слотах, правые кромки денег совпадают. Колонок при этом НЕТ: нет шапки, нет общей рамки, у
   одной строки нет «пустой клетки» — токен расхода просто не существует, пока расход не включён.

Против «одной карточки с тремя колонками» (попытка 1) это не рецидив, а её противоположность:
там колонку объявляла ШАПКА, которой у одной строки нечего подписывать. Здесь строку читают слева
направо как фразу счёта, а совпадение вертикалей — бесплатный побочный эффект, работающий только
там, где строк больше одной.

## 4. Спецификация

### 4.1. Каркас

```
Гуттер листа 16 · доска 370
└─ Эйбрау группы (RowGroupHeader)      высота 14, поля 16, снизу 6
└─ Карточка группы: t.surface, радиус t.radius.card (10), borderCurve continuous,
   boxShadow t.cardShadow, paddingHorizontal 12, paddingVertical 0
   ├─ Строка 1                          48
   ├─ шов: 1pt t.separator, отступ слева 12 (под левой кромкой количества)
   ├─ Строка 2                          48
   └─ [панель барабана]                 под своей строкой, внутри карточки
└─ [панель «Как считаем»]               под карточкой, во всю доску 370
```

Вторая вёрстка карточки не заводится: это `RowGroupBody` из `card-rows.tsx`.

### 4.2. Строка: слоты и краски

| Слот | Ширина | Содержимое | Кегль / краска |
|---|---|---|---|
| Количество | 72 при лестнице, 56 когда строка одна | «от » + число + « » + единица | «от» 15/400 `t.faint` · число 16/600 `t.ink` tabular · единица 15/500 `t.sub` |
| Цена | flex, min 78, ВПРАВО | «€» + число (+ суффикс режима) | «€» 15/500 `t.sub` · число 16/600 `t.ink` tabular |
| Время | 96, ВПРАВО | число + «ч»/«мин» | число 16/600 `t.ink` tabular · частицы 15/500 `t.sub` |
| Расход | 72, ВПРАВО, только если включён | «−€» + число | всё 16/600 и 15/500 в `t.sub` |

**Три кегля на строку и ни одного четвёртого** (закон ДС «max 3 type sizes»): 16 — значения,
15 — частицы, 11 — капс эйбрау. Все `Text`/`TextInput` получают
`maxFontSizeMultiplier={1.2}` и `fontVariant: ["tabular-nums"]` на числах (класс
`tabular-nums` — доказанный no-op, ДС §2).

**Почему расход целиком тише цены.** Красным он быть не может: `danger` в продукте означает долг и
разрушение, а расход — не транзакция. Полным `ink` он быть не должен: до клиента он не доходит
вовсе и в счёте не печатается. `t.sub` + знак «−» — ровно его громкость.

**Почему «от» появляется только при лестнице.** У одной строки сравнивать не с чем, и «от 1» —
определение, которое не пишут (это уже действующее правило: заголовок блока рождается со ВТОРЫМ
количеством). Экономия — 16pt, которые уезжают в цену.

**Почему зазор перед временем 12, а не 8.** Цена выровнена вправо, время — тоже; между правой
кромкой цифры цены и левой границей нажимаемого времени должно оставаться расстояние, которое
палец не перепрыгнет. 8pt — это 1,5мм, промах гарантирован.

### 4.3. Что видно всегда

Всё. Ничего не сворачивается, ничего не появляется по наведению. Строка в покое — это четыре (или
три) числа на белом, без единой заливки, без рамок, без шевронов. **Заливка в строке появляется
ровно в одном случае — под кареткой** (§4.6).

### 4.4. Что по тапу

| Куда | Что происходит |
|---|---|
| Число цены | Каретка, `decimal-pad`, `selectTextOnFocus`. Слот белеет в `t.fill` (§4.6) |
| Число расхода | То же |
| Число количества (строки лестницы) | То же; правит `min_quantity` |
| Число количества (ПЕРВАЯ строка) | Числа «1» править нечем → открывается панель «Как считаем» |
| Частица единицы («шт», «м²») в любой строке | Панель «Как считаем» |
| Слот времени целиком (96×48) | `TimeWheelPair` ЧЧ:ММ под этой строкой, внутри карточки |
| Чип «за всё ⌄» в эйбрау | Панель «Как считаем» |
| Долгое нажатие на «€» цены или расхода | Панель «Как считаем» — дублёр требования «тап по подписи цены даёт режим»: подписи больше нет, целью становится знак валюты |
| «＋» справа в эйбрау | Новое количество последней строкой + `scrollToEnd` |

**Панель «Как считаем»** — ОДНА на услугу, раскрывается ПОД карточкой группы, во всю доску 370,
`t.fill`, радиус 10, поле 12, отступ сверху 8. Три ряда пилюль (`PanelOption`, `minHeight` поднять
с 38 до **44**, idle — `t.surface` на фоне `t.fill`, выбранное — `t.accent`/`t.onAccent`):

```
Считаем      [ За всё ]  [ За 1 м ]
Единица      [ Без единицы ] [ шт ] [ м ] [ м² ] [ м³ ] [ ч ] [ компл ] [ кг ] [ л ]
             [ ＋ Расход ]            ← или [ Убрать расход ], если он включён и всюду нулевой
```

Ряды подписаны `FieldLabel` 13/600 `t.caption` — это панель настройки, а не строка данных, и
здесь подписи стоят на своём месте.

**Почему панель, а не лист.** Лист услуги сам является `BottomSheet` (RN `Modal`) — второй лист
уйдёт ЗА него. По тому же доводу подтверждение удаления — системный `Alert`.

**Почему расход включается на всю услугу, а не построчно.** Расход, стоящий во второй строке и
отсутствующий в первой, ломает вертикальное чтение лестницы (дыра в столбце) — а сравнивать
деньги построчно и есть единственная причина, по которой расход просили ПОКАЗЫВАТЬ, а не прятать.
Плюс это снимает с трёх строк три акцентных надписи «＋ Расход»: N кнопок, делающих одно и то же,
— шум, а не выбор.

**Барабан времени** раскрывается ПОД своей строкой, внутри карточки, шириной 346: `t.fill`,
радиус 10, `WHEEL_H 120` + поля 8/8 = **136pt**. Открытая строка печатает своё время `t.accent`
600 — «что я правлю» показывает МЕСТО, метка не нужна. Открыта всегда ровно одна панель на весь
лист (`openRow`: `null | "settings" | "<rowId>|wheel"`).

### 4.5. Свайп и удаление

Строка лестницы — `SwipeRow`: влево «Убрать», `ACTION_W 96`, `t.danger`, `Trash2`, подтверждение
`Alert` с фразой ступени (`tierSentence`). **У первой строки свайпа нет** — количество «1» это
сама услуга.

**Дублёры жеста (закон ДС «у жеста обязан быть дублёр словом»), их два и оба обязательны:**
1. `accessibilityActions: [{ name: "delete", label: "Убрать количество" }]` на контейнере строки —
   для ротора VoiceOver, которому свайпа не существует;
2. долгое нажатие на **частицу единицы** этой строки → тот же `Alert`. Именно на частицу, а не на
   строку: долгое нажатие по `TextInput` перехватывает iOS (лупа и меню «Выделить/Вставить»), и
   дублёр там физически недостижим.

### 4.6. Фокус

Сфокусированный слот рисует под собой колодец: `t.fill`, радиус 10, вертикальный вылет −6 (высота
36), горизонтальный −6 влево и −6 вправо от границ слота, поверх — врезанное кольцо 1,5pt
`t.accent`, появление 180мс. Число становится `t.ink` 600 (то же, что и было) — цвет здесь не
меняется, меняется материал. На `blur` колодец исчезает.

Пустая цена в покое — «€ —» краской `t.muted`; каретка встаёт после «€».

### 4.7. Пустые состояния

* **Цена пустая ≠ ноль.** «—» `t.muted`, сохранение блокируется («Впишите цену»). Закон оплачен
  бесплатной услугой, уехавшей в счёт.
* **Расход пустой = ноль**, схлопывается в «0» на `blur`: до клиента не доходит, живёт в прибыли.
* **Время пустое** у добавленной строки — «—»; правило `durationForQuantity` идёт сквозь неё.
  У первой строки ноль запрещён валидацией: услуга нулевой длины ломает календарь.
* **Строка без цены И без времени** не сохраняется («Впишите цену или время»,
  `validateServiceEconomics`). Ошибка печатается ОДНОЙ красной строкой под карточкой
  (`RowCaption tone="danger"`) — подпись под конкретной клеткой сломала бы высоту строки.
* **Единица не выбрана** — частицы в слоте количества просто нет: «1», «3», «7». Дверь в панель
  остаётся у первой строки (тап по «1») и у чипа в эйбрау.

### 4.8. Где «＋»

Справа в эйбрау группы, слот `action` у `RowGroupHeader` (уже есть). 15/600 `t.accent`,
`hitSlop 10` → 44×44. Порядок в эйбрау: `ЦЕНА И ВРЕМЯ` — растяжка — `за всё ⌄` — `＋`.
Плюс ОДИН на группу: строка-команда внизу списка требует прокрутки до конца, чтобы сделать то,
что видно сверху.

Новая строка приезжает последней: количество — следующее свободное, время — засеяно
(`createTierDraft`), расход унаследован за одну, **цена ПУСТАЯ** (владелец 21.08: «оно меняет цену
всегда на 50 — мне это не нравится»).

### 4.9. Озвучка (то, что заменило подписи)

Подписи ушли с экрана, но не из продукта. `accessibilityLabel` каждого токена:
«Количество, 3 метра» · «Цена за всё, 135 евро» · «Время на всё, 1 час 30 минут» ·
«Расход за всё, 18 евро». В режиме «за одну» — «Цена за 1 метр, 45 евро». Это не украшение: для
незрячего частица «€» подписью не является.

## 5. «За всё» против «за одну»

Переключатель ОДИН на услугу (`price_entry`). В базе значение как лежало ЗА ВСЁ, так и лежит;
перевод живёт на двух границах (`displayValue` / `draftValue`).

| | Режим «За всё» | Режим «За 1 м» |
|---|---|---|
| Чип в эйбрау | `ЗА ВСЁ` | `ЗА 1 М` (имя берётся из единицы; без единицы — `ЗА ОДНУ`) |
| Слот цены | «€135» | «€45 /м» — суффикс 15/500 `t.sub`, +12,45pt |
| Слот времени | «1 ч 30 мин» | «30 мин /м» |
| Слот расхода | «−€18» | «−€6 /м» |
| Без единицы | «€135» | «€45 за 1» — суффикс 29,7pt |
| Под барабаном | ничего | «30 мин × 3 = 1 ч 30 мин» 13/400 `t.sub` |

**Суффикс обязателен, и это не украшение.** Пара «3 шт   €45» без суффикса в режиме «за одну»
читается как «три штуки за сорок пять» — прямая ложь про деньги, единственная настоящая мина
режима. Суффикс её снимает четырьмя точками ширины.

**Арифметика суффикса.** Цена «за 1 м» худшая: 78,7 + 12,45 = 91,2 при слоте 78 (лестница с
расходом) → `adjustsFontSizeToFit`, `minimumFontScale 0.9` → 82,1, всё ещё >78 → фактический
масштаб 0,86 (эффективные 13,7pt). Это худший из худших случаев: четырёхзначная цена С КОПЕЙКАМИ
плюс включённый расход плюс лестница. На проде копеек нет ни в одном из шести прайсов, расход
нулевой у всех шести. Типичное «€45 /м» = 50,9 в 78 ✓.

Переключение НЕ трогает `price_tiers`/`duration_tiers`/`cost_tiers` и не округляет сохранённое:
100 «за всё» показывается как 33,33 «за одну», и если человек ничего не напечатал, обратно выйдет
ровно 100.

## 7. Риски

**Где палец промахнётся.**
1. **Шов «цена | время».** Цена выровнена вправо, время начинается через 12pt. Тап в 4–6pt правее
   последней цифры цены открывает БАРАБАН вместо каретки — самая частая ошибка этой раскладки.
   Смягчено зазором 12 (не 8) и тем, что цена — самая широкая цель строки (78–174pt).
2. **Частица единицы «м²» — 13,5pt в ширину**, а по ней тап открывает панель. Цель добирается
   `hitSlop {top:8,bottom:8,left:6,right:10}` и тем, что весь слот количества у ПЕРВОЙ строки
   ведёт туда же. У строк лестницы левая часть слота — поле ввода, и промах по частице попадёт в
   каретку количества. Терпимо: обе двери в панель есть и выше (чип в эйбрау).
3. **Свайп по строке с тремя `TextInput`.** Горизонтальный пан, начатый на поле, может быть съеден
   фокусом. `SwipeRow` в продукте живёт на строках без ввода. Проверять В СИМЕ первым делом; если
   жест воюет — свайп остаётся, но основной дорогой удаления становится долгое нажатие по частице
   единицы и `Alert`.
4. **Барабан внутри карточки** прокручивается вертикально, а лист услуги прокручивается тоже:
   родительский `ScrollView` обязан отдавать жест барабану (уже работает у раскрытого барабана в
   нынешнем блоке — раскладку это не меняет).

**iPhone SE (375pt).** Доска `375 − 32 = 343`, содержимое строки `343 − 24 = 319`, то есть на 27pt
меньше. Раскладки ведут себя так:
* одна строка без расхода: цена 147 вместо 174 — **запас гигантский, ничего не меняется**;
* лестница без расхода: цена 131 — ✓;
* лестница + расход: цена `319−72−8−12−96−8−72 = 51`. «€1 250,50» (78,7) сжимается до 0,65 —
  **это провал.** Правило: при ширине экрана < 390 расход НЕ становится четвёртым токеном, а
  печатается второй строкой внутри той же строки-контейнера, справа: строка вырастает с 48 до 70.
  Плата платится ровно теми услугами, у которых расход есть, — на проде их ноль.

**Крупный системный шрифт (`maxFontSizeMultiplier 1.2`).** Держатся: «от 3 шт» (61,0 ≤ 72),
«€1 250» (62,6 ≤ 78), «30 мин» (60,1 ≤ 96), «−€250» (52,4 ≤ 72). НЕ держатся три случая, и я
называю их прямо:
* «от 128 м²» = 80,4 > 72 → `adjustsFontSizeToFit`, масштаб 0,9;
* «1 ч 30 мин» = 92,9 ≤ 96 ✓, но «23 ч 55 мин» = 104,4 > 96 → масштаб 0,92;
* «€1 250,50» = 94,4 при слоте 78 (лестница+расход) → масштаб 0,83.

Все три — крайние значения, которых нет ни в одном из шести живых прайсов (услуг длиннее десяти
часов нет, копеек нет, трёхзначных количеств нет). Это допущение, а не доказательство; клипа при
этом не происходит НИГДЕ — числа сжимаются, а не обрезаются. Эйбрау и пилюли панели живут при
`maxFontSizeMultiplier 1.3`, у них места вдоволь.

**Чего этот дизайн не умеет.** Пятый токен в строку не влезет никогда: 346 разобраны без остатка.
Следующее расширение обязано ломать структуру (у количества появляется своя страница), а не
подрезать поля — это конструктивный потолок, тот же, что был назван 21.08 для четвёртой колонки.

## 9. Открытый вопрос владельцу

**Строка лестницы означает «от 3» или «ровно 3»?** Сейчас в продукте это ПОРОГ («от 3 — €135 за
всё»), и частица «от» съедает 16pt слева. Но живая строка счёта на проде — «Трасса, 4 м», ×4 по
€20, то есть человек продал КОНКРЕТНОЕ количество, а не порог. Если лестница на самом деле про
конкретные количества, «от» уходит совсем (слот 56 вместо 72, цене прибавляется 16pt), и строка
услуги становится буквально строкой счёта. Ответ меняет и слово, и арифметику — поэтому спрошено
до кода.
