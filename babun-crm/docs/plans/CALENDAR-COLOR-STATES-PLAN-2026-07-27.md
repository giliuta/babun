# Цвет записи = стадия жизни заявки (план, 2026-07-27)

Владелец, 2026-07-27 (сессия «календарь и заявка»): цвет всей записи в
календаре должен рассказывать, НА КАКОЙ СТАДИИ заявка, — и переключаться
автоматически. Делаем ПОСЛЕ доводки клиентов/финансов, когда возьмёмся за
внутренности самой заявки. Здесь — зафиксированная логика, чтобы не потерять.

## Автоматическая лестница (дефолты; каждый цвет настраивается)

| Стадия | Сигнал в данных | Цвет (дефолт) |
| --- | --- | --- |
| Новый клиент, объекта нет | запись есть, у клиента нет объекта/адреса выезда | фиолетовый |
| Объект внесён («куда ехать» известно) | появился location/address | синий |
| Завершено, оплата наличными | status=completed + payment method cash | зелёный |
| Завершено, оплата картой | completed + card | голубой |
| Инвойс выставлен | invoice по appointment_id в статусе «выставлен» | серый |
| Инвойс оплачен | invoice оплачен | светло-голубой |

- Переходы автоматические: внесли объект → цвет сам сменился; оплатили →
  сменился по способу оплаты.
- **Ручной цвет побеждает и ВЫКЛЮЧАЕТ автоматику** для этой записи
  (сегодняшний `color_override` — уже правильный крючок: он и так первым
  в приоритете полосы, см. `apps/mobile/src/features/calendar/status-colors.ts`).
- Все соответствия «стадия → цвет» живут в настройках (владелец сам
  перекрашивает диапазоны). Никакой второй шкалы смыслов: цвет = стадия,
  команда остаётся на полосе слева.

## Что трогаем, когда придёт время

- `status-colors.ts` — сейчас цвет = status (scheduled/in_progress/…).
  Станет: резолвер стадии из (клиент.объекты, appointment.location_id,
  status, способ оплаты, связанный инвойс) → цвет из настроек; fallback —
  сегодняшняя логика.
- Способ оплаты и инвойс уже в данных (финансы: computeFinancials,
  invoices.appointment_id) — новых полей в схеме не ожидается, кроме,
  возможно, таблицы/JSON настроек «стадия → цвет».
- Настройки — в «Настройках календаря» или «Кабинете», решим при верстке;
  дефолты выше.

Связано: identity-tint на экране /book (выбор цвета красит страницу) — при
внедрении автолестницы ручной выбор там и есть «ручной цвет, автоматика off».
