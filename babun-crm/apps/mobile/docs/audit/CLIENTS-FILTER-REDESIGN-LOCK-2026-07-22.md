## Закрытые претензии владельца
1. **Центр шапки** — `72│flex-центр│92` слоты, «Фильтры» оптически по центру всегда; «Сбросить» без клипа (слот 92pt).
2. **«A/C» непонятно** — Сортировка = СТРОКИ (подпись слева + подсказка направления справа `faint`); `SORT_LABELS.equipment` «A/C»→«По технике», `SORT_HINTS` для всех 4.
3. **«на фига этот 1»** — счётчики УБРАНЫ со всех контролов (статусы + фасеты). Число только в результате (футер «Показать N» + бар «Найдено N»). `segmentCounts` = только гейт видимости чипа.
4. **Красиво/симметрия** — белый `surface`, ритм gutters/gap 20, токен-радиусы, правило нечётного хвоста (последний чип `width 100%`), монохромные eyebrow (иконка `sub 16` + подпись `13/600 sub` sentence-case), 44pt.
5. **Новые фильтры** — статусы «Без записи» (`visits>0 && nextApt===null`) и «Напомнить» (`reminder_at ≤ сегодня`) в мультивыбор `SEGMENT_OPTIONS`/`matchesSegment`.
6. **Доступность/состояния** — checkbox-роль мультивыбора / radio одиночного (Период/Сортировка), header-роль eyebrow, Dynamic Type (cap 1.2 в шапке), авто-скрытие пустых секций, 0-выдача гасит CTA + подсказка «Смягчите условия».

Плюс: теги → OR-внутри (единая семантика фасетов; между секциями AND).

## Порядок секций
Статус · Команда · Метка · Тег · Период — линия — Сортировка. Фасеты/enum авто-скрыты при пустоте.

## Решения по дырам приёмки (зафиксированы)
- Счётчики фасетов — тоже убраны (не только статусы), чтобы не спорить с «число после выбора».
- Сорт-слово одно: «По технике» (совпадает с `SORT_LABELS_LONG` + hint + фильтром «Тип техники» из Фазы 2).
- Период нейтраль = «Всё время» (radio, `period=null`).
- «Изменить» теги НЕ добавляли (коллизия с «Очистить» + потеря состояния при router.push) — Фаза 2.
- Facet-dimming убран вместе с числом (грей без числа путал).

## Фаза 2 (НЕ в локе — по greenlight владельца)
- ~~**Обслуживание (ТО)**~~ — СНЯТО 2026-07-22: вертикально-специфичное, не для SaaS-фильтров.
- **Enum-фасеты**: Тип объекта (`property_type`+`PROPERTY_LABELS`), ~~Тип техники~~ (СНЯТО 2026-07-22, вертикальное), Источник (`acquisition_source`+`ACQUISITION_LABELS`) — 2-кол чипы, OR-внутри, авто-скрытие при `<2` значениях.
- **Диапазоны**: «Долг ≥ €» / «Доход ≥ €» (степпер-пресеты) — согласовать дефиницию долга.
- **Умные списки** (сохранённые наборы фильтров) — новая персистентность.
- **«Изменить» теги** → существующий `app/(dashboard)/clients/tags.tsx` (нужна реконсиляция stale-выбора + сохранение состояния листа).
