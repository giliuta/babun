# Babun CRM — правила проекта

> **ПЕРВОЕ ДЕЙСТВИЕ В СЕССИИ: прочитай [`AGENTS.md`](AGENTS.md) целиком.**
> Правил здесь нет — они все там, и без них работать нельзя.

Харнесс подгружает в контекст именно этот файл, поэтому соблазн держать
правила здесь велик. Так уже было: лежали две копии одного текста, копии
разошлись, и в одной оказалось «ВСЕГДА пушь в `master`», а в другой —
«НИКОГДА не пушь без разрешения владельца». Канон один — `AGENTS.md`.
Этот файл своих правил не содержит и заводить их не должен: любое новое
правило пишется в `AGENTS.md`, сюда — максимум ссылка.

Действует более строгая формулировка: **push, PR и deploy — только по явной
просьбе владельца.**

Специфика Claude Code (команды `/plan`, `/implement`, `/test` и доменные
агенты) — в `.claude/commands/` и `.claude/agents/`; индекс агентов —
[`docs/agents.md`](docs/agents.md).
